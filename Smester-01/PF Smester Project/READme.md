# 🎮 Tetris Game – Programming Fundamentals Project

## 📌 Project Overview

This project is a **Tetris Game** developed as a semester project for the subject **Programming Fundamentals (PF)**.

The game is developed using **C++ and SFML (Simple and Fast Multimedia Library)** to provide a graphical gaming experience. It is based on the classic Tetris gameplay, where players arrange falling blocks to complete horizontal lines and score points.

The project focuses on applying fundamental programming concepts through a practical game development project.

## 🎯 Project Objectives

- Understand and apply fundamental C++ programming concepts.
- Learn how to use arrays to manage game data and block positions.
- Use functions to organize different game operations.
- Understand basic game logic and event handling.
- Explore graphical programming using the SFML library.

## 🛠️ Technologies Used

- **C++:** Main programming language.
- **SFML:** Used for graphics, window management, and game interaction.
- **Visual Studio:** Development environment.

## ✨ Game Features

- Classic Tetris gameplay.
- Different shapes of falling blocks.
- Block movement and rotation.
- Horizontal line detection and clearing.
- Score management.
- Graphical interface using SFML.
- Keyboard-based game controls.

## 🧠 Programming Concepts Implemented

The project demonstrates the practical use of the following concepts:

- **Arrays:** Used to manage the game grid and block-related data.
- **Functions:** Used to handle different game operations and organize the code.
- **Conditional Statements:** Used to manage game rules and decision-making.
- **Loops:** Used for continuous game execution and processing.
- **Variables:** Used to store game information such as positions and scores.
- **Event Handling:** Used to process player input through SFML.

## ▶️ How to Run the Project

1. Download or clone this repository.
2. Open the project in Visual Studio.
3. Make sure SFML is properly installed and configured.
4. Configure the required SFML libraries and dependencies.
5. Build and run the project.

**Requirement:** A compatible C++ compiler and SFML library are required to run the game.
