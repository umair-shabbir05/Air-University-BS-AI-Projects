# 🍽️ Restaurant Website – AICT Semester Project

## 📌 Project Overview

This project is a **frontend restaurant website** developed as a semester project for the subject **Applications of Information and Communication Technologies (AICT)**.

The website is designed to represent a restaurant's online presence and provide visitors with basic information about its services, food menu, and contact details.

It is a single-page website developed using **HTML and CSS**, focusing on website structure, styling, and user-friendly design.

## 🎯 Project Objectives

- Understand the basic concepts of web development.
- Apply HTML to create the structure of a website.
- Use CSS to design and style web pages.
- Develop a practical website based on a real-world business.
- Explore CSS hover effects and other styling techniques.

## 🛠️ Technologies Used

- **HTML5:** Used to structure the website and its content.
- **CSS3:** Used for styling, layouts, visual effects, and hover effects.

## ✨ Website Features

The website contains four main sections on a single page:

1. **Home:** Introduces the restaurant and provides an overview.
2. **Menu:** Displays the restaurant's food menu.
3. **About:** Provides information about the restaurant.
4. **Contact Us:** Displays contact-related information.

### Additional Design Features

- Single-page website layout.
- CSS hover effects for interactive elements.
- Styled navigation and website sections.
- Attractive visual presentation.
- Organized content and styling.

## ▶️ How to Run the Project

1. Download or clone this repository.
2. Open the `AICT-Semester-Project` folder.
3. Locate the `index.html` file.
4. Double-click `index.html` to open it in your web browser.
5. Explore the different sections of the website.

No additional software or server setup is required to view the basic website.
